# 기도로 짓는 집

기도 시간이 쌓일수록 어둠 속에서 집의 도면이 한 획씩 그려지는 페이지입니다.
**1000시간**이 모이면 도면이 실제 집으로 바뀝니다.

휴대폰 세로 화면에 맞춰 만들었습니다.

```
prayer/index.html            페이지 (한 파일)
prayer/server/Code.gs        구글 스프레드시트 누적 서버 (Apps Script)
prayer/server/supabase.sql   Supabase 테이블 + 정책
```

## 어떻게 보이나

- **0시간** — 거의 검은 화면. 지반선 하나 없습니다.
- **쌓이는 동안** — 바탕이 검정에서 흐린 청색으로 물들고, 도면이 **아래에서 위로**
  그려집니다. 지반 → 벽 → 1층 창 → 현관 → 2층 창 → 처마 → 지붕 → 지붕창 → 굴뚝 → 창살.
  기도가 집을 세워 올리는 순서 그대로입니다.
- **1000시간** — 도면이 **부피를 얻습니다.** 입면도의 모서리가 한 방향으로 밀려 나가
  옆벽과 지붕면이 생기고, 벽에 색이 차고 창에 불이 켜집니다. 도면 용지는 사라지고
  실제로 지어진 집만 남습니다.

**쌓인 시간은 화면에 숫자로 표시하지 않습니다.** 얼마나 그려졌는지만 보입니다.

## 화면 구성

전체가 **건축 도면 한 장**입니다. 도면 테두리, 모서리 지시선, 왼쪽 높이 치수,
기준 축선, 오른쪽 아래 표제란(`WELCOME HOME / FRONT ELEVATION / SCALE 1:100`).
0시간일 때는 빈 용지만 희미하게 놓여 있고, 기도가 쌓이며 그 위에 집이 그려집니다.

기도 시간은 휠을 돌려 고릅니다. 30분부터 24시간까지이고,
손가락으로 굴리거나 항목을 눌러도 되고, 위아래 방향키로도 움직입니다.

## 서버 붙이기

붙이지 않으면 그 기기에만 쌓입니다. 여러 사람의 기도가 합쳐지려면 둘 중 하나를 쓰세요.

### Apps Script

1. 구글 스프레드시트 → **확장 프로그램 → Apps Script**
2. [`server/Code.gs`](server/Code.gs) 를 통째로 붙여넣고 저장
3. **배포 → 새 배포 → 웹 앱** / 실행 계정 **나** / 액세스 권한 **모든 사용자**
4. 나온 웹 앱 URL 을 `index.html` 의 `var SERVER_URL = "";` 에 넣습니다

시트에는 시간·기도제목·마음의 감동이 모두 쌓이지만, **페이지가 읽는 것은 합계뿐입니다.**
공개 주소로 기도제목 본문이 나가지 않습니다.

### Supabase

1. [`server/supabase.sql`](server/supabase.sql) 을 SQL Editor 에 붙여넣고 Run
2. **Project Settings → API** 에서 Project URL 과 **anon public** 키를 복사
3. `index.html` 의 `var SUPABASE = { url: "", anonKey: "" };` 에 넣습니다

여기서도 본문은 읽기를 막고 `prayer_hours` 뷰로 시간만 내보냅니다.

> 파일을 고치기 어려우면 주소 뒤에 `?server=<웹앱URL>` 또는 `?sb=<URL>,<anon키>` 를
> 붙여 한 번 접속해도 **그 기기에** 저장됩니다. 다만 참여자 모두에게 적용하려면
> 파일에 직접 넣어야 합니다.

## 목표 시간 바꾸기

`index.html` 의 `var GOAL_HOURS = 1000;` 한 줄입니다.
