# 인생네컷 — 웹캠 포토부스

스마트폰이나 PC 웹캠으로 **여덟 장을 찍고 → 네 장을 고르고 → 매수를 정해 → 인쇄**하는
한 장짜리 페이지입니다. 사진은 서버로 올라가지 않고 **그 기기 안에서만** 처리됩니다.

```
photo/index.html              페이지 전부 (HTML·CSS·JS 한 파일)
photo/server/print-server.js  자동 인쇄 서버 (Node 18+, 설치할 것 없음)
```

---

## 1. 제일 빠른 길 — 인쇄까지 자동으로

프린터가 꽂힌 노트북/PC 에서 터미널을 열고:

```bash
node photo/server/print-server.js
```

그리고 그 컴퓨터의 브라우저로 **http://localhost:8787** 을 엽니다. 끝입니다.

- `localhost` 라서 카메라 권한이 정상으로 열립니다 (카메라는 https 또는 localhost 에서만 켜집니다)
- 준비 화면의 **프린터** 칸에 초록 불이 들어오고, 연결된 프린터 목록이 뜹니다
- **인쇄** 버튼을 누르면 대화상자 없이 곧바로 프린터로 나갑니다

프린터를 하나로 고정하려면:

```bash
node photo/server/print-server.js --printer "Canon SELPHY CP1500" --port 8787
```

| 옵션 | 뜻 |
|---|---|
| `--port 8787` | 포트 (기본 8787) |
| `--printer "이름"` | 프린터 고정. 페이지에서 고른 값보다 우선합니다 |
| `--host 0.0.0.0` | 같은 와이파이의 다른 기기에서도 접속 허용 |
| `--no-fit` | CUPS 의 `fit-to-page` 를 끕니다 (여백이 생길 때) |

서버가 하는 일은 하나입니다. 페이지가 보낸 PNG 를 임시 파일로 저장한 뒤
macOS·리눅스는 `lp`, 윈도우는 `mspaint /pt` 로 인쇄를 거는 것. 1분 뒤 임시 파일은 지워집니다.

---

## 2. 서버 없이 — 크롬 키오스크 인쇄

서버를 띄우기 번거로우면, 크롬을 **인쇄 대화상자 없이** 띄우는 방법이 있습니다.
기본 프린터로 바로 나갑니다.

```bash
# macOS
open -a "Google Chrome" --args --kiosk-printing --kiosk https://내주소/photo

# Windows (바로가기 속성 → 대상 뒤에 붙이기)
chrome.exe --kiosk-printing --kiosk https://내주소/photo
```

`--kiosk` 까지 넣으면 전체화면 무인 부스가 됩니다. 종료는 `Alt+F4`.
이 방법에서는 **매수만큼 페이지를 겹쳐 보내서** 원하는 장수를 뽑습니다.

둘 다 안 되면? 그냥 평범한 인쇄창이 뜹니다. 페이지는 항상 이 순서로 시도합니다.

> 인쇄 서버 → (없으면) 브라우저 인쇄 → 언제든 **저장** 버튼으로 PNG 내려받기

## 3. 스마트폰으로 찍으려면

폰 카메라를 쓰려면 페이지가 **https** 여야 합니다. 두 가지 방법이 있습니다.

**A. 배포해서 쓰기 (간단)** — 이 저장소를 Vercel 에 올리면 `https://내주소/photo` 로 열립니다.
폰에서 찍고 고르고, 인쇄는 폰의 **AirPrint / Mopria** 로 나갑니다 (인쇄창이 한 번 뜹니다).
자동 인쇄 서버 칸은 비워 두세요.

**B. 폰으로 찍고 자동 인쇄까지 (무인 부스)** — PC 에서 인쇄 서버를 띄운 뒤 https 통로를 하나 냅니다.

```bash
node photo/server/print-server.js --host 0.0.0.0
cloudflared tunnel --url http://localhost:8787      # 또는 ngrok http 8787
```

발급된 `https://....trycloudflare.com` 주소를 폰으로 열면, 페이지와 인쇄 서버가 **같은 주소**라
카메라도 켜지고 인쇄도 자동입니다. 준비 화면의 서버 주소 칸은 비워 두거나 그 https 주소를 그대로 넣으세요.

> https 페이지에서 `http://localhost` 로 인쇄를 보내는 방식은 크롬에서는 되지만
> 사파리·일부 브라우저가 막습니다. 그래서 위의 A·B 를 권합니다.

## 4. 인화 규격

준비 화면에서 고릅니다. 한 컷의 비율은 종이 크기에서 자동으로 계산되고,
촬영 화면의 미리보기도 그 비율로 맞춰집니다. 출력은 **300dpi PNG**.

| 규격 | 종이 | 결과 | 어디에 |
|---|---|---|---|
| **4×6인치 · 2컷 스트립 ×2** | 101.6×152.4mm (1200×1800px) | 5×15cm 스트립 두 장, 가운데를 자름 | 4×6 인화지를 쓰는 대부분의 포토프린터 |
| **2×6인치 스트립 1장** | 50.8×152.4mm (600×1800px) | 스트립 한 장, 자를 필요 없음 | DNP DS-RX1HS, 시티즌 CX-02 등 2컷 지원 기종 |
| **엽서 100×148mm · 스트립 ×2** | 100×148mm (1181×1748px) | 스트립 두 장 | 캐논 셀피 CP 시리즈 (엽서/L 용지) |
| **4×6인치 · 2×2 세로컷** | 101.6×152.4mm | 네 컷을 크게, 자를 필요 없음 | 얼굴 크게 남기고 싶을 때 |

그 밖에 고를 수 있는 것: 사진 톤(원본·흑백·필름·화사·선명), 테두리 색(화이트·블랙·크림·네이비),
아래쪽 문구와 날짜, 좌우 반전(거울), 카운트다운 3초/5초, 인쇄 매수 1~20장.
고른 값은 그 기기에 기억됩니다.

주소 뒤에 붙일 수 있는 것:

```
?layout=strip-4x6 | strip-2x6 | postcard | grid-4x6
?agent=http://localhost:8787
```

## 5. 프린터별 메모

- **캐논 셀피 CP1500** — 엽서(P) 용지 + `엽서 100×148mm` 규격. 드라이버에서 "여백 없음"을 켜 두세요.
- **DNP·시티즌 염료승화 프린터** — 2×6 컷 모드를 프린터 쪽에서 먼저 켜야 `2×6인치` 가 제대로 나옵니다.
- **일반 잉크젯 + 4×6 인화지** — `4×6인치` 규격에 "테두리 없음(Borderless)" 설정을 함께 쓰세요.
- **가장자리가 잘려 나올 때** — 프린터의 확대 인쇄를 끄고, 서버를 `--no-fit` 으로 다시 띄웁니다.
- **색이 어둡게 나올 때** — 사진 톤을 `화사` 로 두면 인화지에서 한결 낫습니다.

---

## 6. 잘 안 될 때

| 증상 | 이유와 해결 |
|---|---|
| 카메라가 안 켜짐 | 주소가 `http://` 로 시작하면 (localhost 제외) 브라우저가 카메라를 막습니다. https 주소나 `http://localhost:8787` 로 여세요 |
| 카메라 목록이 비어 있음 | 브라우저 주소창 왼쪽 자물쇠 → 카메라 **허용** 후 새로고침 |
| 프린터 칸이 빨간 불 | 서버가 안 떠 있거나 주소가 다릅니다. `node photo/server/print-server.js` 실행 후 **프린터 다시 확인** |
| 프린터 목록이 비어 있음 | macOS·리눅스는 `lpstat -a`, 윈도우는 PowerShell `Get-Printer` 가 프린터를 보여주는지 먼저 확인하세요 |
| 인쇄는 되는데 여백이 큼 | 프린터 드라이버의 용지 크기를 실제 인화지에 맞추고, "여백 없음"을 켜세요 |
| 아이폰에서 소리가 안 남 | 무음 스위치를 풀고, **촬영 시작**을 한 번 눌러 주면 그다음부터 납니다 |
